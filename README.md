# YatraVerse 🌏

> **Your Journey. Your Story. Your Yatra.**

A production-grade travel discovery and AI trip-planning platform built with
React + FastAPI + PostgreSQL.

![status](https://img.shields.io/badge/status-in--development-orange)
![license](https://img.shields.io/badge/license-MIT-blue)

---

## ✨ Features

| Area | Capabilities |
|---|---|
| Discovery | Search, filter, and sort 15+ Indian destinations |
| Destination Details | Gallery, attractions, activities, hotels, tips, weather, map |
| Trip Planner | Multi-step planner with travel style + interests |
| AI Itinerary | Day-wise plans with morning/afternoon/evening, costs, travel time |
| My Trips | Upcoming / completed trips, duplicate, edit, delete |
| Favorites | Save & manage destinations |
| Budget Calculator | Per-person cost, daily average, remaining budget, charts |
| Weather | Current + forecast, provider-agnostic abstraction layer |
| Auth | JWT, hashed passwords, protected routes, persistent login |
| Profile | Preferences, stats, editable profile |

---

## 🧱 Tech Stack

**Frontend** — React 18, Vite, JavaScript, Tailwind CSS, React Router v6,
Axios, Lucide React, Framer Motion, Recharts

**Backend** — Python 3.11, FastAPI, Pydantic v2, SQLAlchemy 2.0, Alembic

**Database** — PostgreSQL 16

**Auth** — JWT (python-jose), bcrypt (passlib)

**AI** — Provider-agnostic service layer (OpenAI / Gemini / mock fallback)
